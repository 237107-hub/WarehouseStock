# Лабораторна робота 6

Варіант 6, WarehouseStock. Студент Здравков Максим Юрійович, група 471.
Гілка `lab6-refactoring`. ЛР1–5 збережені; успадкований модуль ізольовано в src/Legacy.

## Запуск
1. Розпакуйте весь ZIP у звичайну папку. Не відкривайте .sln усередині ZIP.
2. Відкрийте WarehouseStock.sln. Для цієї роботи стартовий проєкт — WarehouseStock.Legacy.Demo.
3. Або виконайте `dotnet run --project src/Legacy.Demo`.
4. `dotnet test` запускає 95 тестів: 65 попередніх і 30 характеризаційних.
5. `dotnet build -c Release` перевіряє всі проєкти; ціль .NET 8.

Демонстрація друкує документ із сумою 655.00 UAH, журнал та ERR: empty. Надсилання листа лише імітується записом у журнал.

## Матеріали
docs/smells.md — 10 дефектів; docs/metrics-before.json і metrics-after.json — вимірювання Roslyn; docs/refactoring-journal.json — дев'ять окремих refactor-комітів; docs/evidence — фактичні текстові протоколи тестів; docs/tech-debt.md — 6 пунктів, умовно 11 год / 3300 грн.

Очікувані значення тестів не змінено. Після завершення дозволено лише форматування пробілів; послідовність токенів тестового файла перевірено автоматично. Прогони історичних комітів 3 і 6 та початкового коміта з тестами повторено окремо.
