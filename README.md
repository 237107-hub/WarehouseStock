# WarehouseStock

Навчальний проєкт з дисципліни «Конструювання програмного забезпечення».
Варіант №6: складські залишки та переміщення товару.

## Призначення

Облік документів переміщення товарів між складами.
На етапі лабораторної роботи №1 реалізовано доменні сутності,
додавання позицій і розрахунок загальної вартості переміщення.

## Склад рішення

- WarehouseStock.Core — бібліотека предметної області.
- WarehouseStock.App — консольний застосунок для демонстрації.
- CODING_STANDARD.md — стандарт кодування.
- .editorconfig — правила форматування та іменування.
- Directory.Build.props — спільні налаштування аналізаторів.

## Вимоги

.NET SDK 8 або новіший із підтримкою net8.0.
Для запуску потрібне середовище виконання .NET 8.
Для першого відновлення пакетів потрібне з'єднання з NuGet.
Для історії змін використовується Git.

## Складання та запуск

Виконувати з кореня рішення:

    dotnet build
    dotnet run --project WarehouseStock.App

Демонстрація створює переміщення зі складу 10 до складу 20.
Дві позиції: 2 × 149.50 та 1 × 89.90. Очікувана сума: 388.90.

## Перевірка якості

    dotnet format --verify-no-changes
    dotnet clean
    dotnet build

Докладні правила наведено в CODING_STANDARD.md.
Roslyn та StyleCop перевіряють код обох проєктів.

## Обмеження поточного етапу

Дані зберігаються в пам'яті. База даних і графічний інтерфейс відсутні.
Перевірку залишків та правила переходів між станами буде додано
в наступних лабораторних роботах.
