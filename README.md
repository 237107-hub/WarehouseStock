# WarehouseStock

Навчальний проєкт з дисципліни «Конструювання програмного забезпечення».
Автор: Здравков Максим Юрійович, група 471. Варіант №6:
складські залишки та переміщення товару.

## Склад рішення

- WarehouseStock.Core — бібліотека предметної області.
- WarehouseStock.Core/Domain — скелет сутностей із ЛР1.
- WarehouseStock.Core/Legacy/StockTransfer.cs — модуль, приведений до стандарту в ЛР2.
- WarehouseStock.App — консольна демонстрація успадкованого модуля.
- docs/lab02 — еталонний вивід, таблиці порушень, перейменувань і констант та технічний борг.

## Вимоги

.NET SDK 8 або новіший із підтримкою net8.0, середовище виконання .NET 8 та Git.
Для першого відновлення пакетів StyleCop потрібен доступ до NuGet або локальний кеш пакетів.

## Складання та запуск

    dotnet build -warnaserror
    dotnet run --project WarehouseStock.App --no-build

ЛР2 демонструє дві позиції: 3 × 250 та 12 × 90. Сума без регулярної
знижки — 2196,0; із регулярною знижкою — 1976,40 (роздільник залежить
від поточної локалі). Далі виводяться результати перевірки документа,
зміни стану та текстовий звіт. Історичний запуск ЛР1 доступний за тегом lab1.

## Перевірка якості

    dotnet format --verify-no-changes
    dotnet clean
    dotnet build -warnaserror

Стандарт наведено в CODING_STANDARD.md та .editorconfig.
Розрахунки й формат виводу ЛР2 збережено відносно docs/lab02/before.txt.
Результат фінального запуску зберігається в docs/lab02/after.txt.

## Обмеження

Дані зберігаються в пам'яті. Немає бази даних і графічного інтерфейсу.
Успадковані правила знижок, текстові позиції та залежність від поточної
культури потребують окремого перегляду; див. docs/lab02/technical-debt.md.
