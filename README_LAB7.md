## Відтворення
- dotnet test — усі тести, включно з попередніми роботами.
- dotnet test tests/WarehouseStock.Tests --filter FullyQualifiedName~Lab07 — нові перевірки.
- dotnet test tests/WarehouseStock.Tests --collect:"XPlat Code Coverage" --settings coverage.runsettings — покриття всього Core.
- У каталозі Coverage архіву збережено справжні звіти до і після: відкрийте after/index.html.
- Запуск.cmd у корені ZIP показує програму ЛР7; потрібен .NET 8 Runtime.

TransferDiscountPolicy — окрема навчальна політика знижки на складське відвантаження: 5% постійному одержувачу, додатково 10% від 1000 включно, округлення ToEven до копійки, стеля 150 грн. Старі правила ЛР3–6 не змінюються.

TDD складається рівно з трьох послідовних комітів: тільки червоний тест, тільки реалізація стелі, рефакторинг. Очікування тестів не підганялися під реалізацію. Навмисна підміна >= на > спричинила падіння двох граничних фактів, після відновлення вони зелені.

FakeTransferRepository зберігає дані у словнику. StubPricingPolicy повертає сталу ціну. SpyNotifier фіксує факт та аргумент сповіщення без реального листа. AddCalls — перевірка взаємодії, Save у нашому інтерфейсі відсутній. У трьох нових тестах сервісу немає файлових чи мережевих звернень. Частина старих регресійних тестів ресурсів працює з тимчасовими файлами.

Core coverage: 365/488 → 439/488 рядків; 69/94 → 82/94 переходів. Усі непокриті точки перелічено у docs/lab07/uncovered-branches.md. Generated code виключено за атрибутами, але невикористані ручні класи залишаються в знаменнику.

GitHub-репозиторію користувач не має; URL і публікація відсутні. ZIP містить локальну .git історію. Перед здачею потрібні URL та реальні знімки екрана запусків, зокрема червоного TDD-тесту. У комплекті замість скриншотів справжні текстові протоколи, а не намальовані зображення. Пагінацію DOCX у Word автоматично перевірити не вдалося.
