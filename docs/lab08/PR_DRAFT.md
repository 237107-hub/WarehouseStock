# Підготувати суворе складання та CI для WarehouseStock

Це підготовлений опис PR. Сам PR не створено та не злито: потрібен GitHub-акаунт користувача.

Спільні властивості задають версію 0.8.0, net8.0, SDK 9.0.318, nullable та TreatWarningsAsErrors. Усі шість проєктів використовують lock-файли. Консоль і CSV мають спільну перевірку вводу. CI виконує locked restore з аудитом, format verify, Release build, тести та поріг рядків Core 80%; TRX і Cobertura зберігаються завжди.

Перевірено локально: 146 тестів, 90.14% рядків Core, 0 попереджень і помилок. Намірений CS0168 дав ненульовий код; наступний коміт відновив перевірки. Експеримент із порогом 99% теж завершився невдало, отже поріг дійсно застосовується.

## Власні зауваження і виправлення
1. CRLF суперечив Linux-перевірці формату: встановлено LF та .gitattributes.
2. Format не перейменував приватні поля previous/processor: вручну додано _ без зміни очікувань тестів.
3. Coverlet collector не застосовує MSBuild Threshold: додано coverlet.msbuild і негативну перевірку 99%.
4. NumberStyles.Number дозволив би кому як роздільник тисяч: залишено лише знак, крапку і пробіли, додано тести коми та експоненти.
5. Розбір консолі і CSV міг розійтися: винесено спільний ParseFields, адаптер консолі делегує йому.
6. Major-теги Actions могли змінюватися: закріплено перевірені SHA; дозволено лише contents: read.
