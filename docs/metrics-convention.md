# Методика вимірювань
Roslyn обчислює CC = 1 + if + цикли + && + || + ?? + ?: + case (без default) + catch.
LOC методу: усі непорожні фізичні рядки від сигнатури до закривної дужки, без окремих рядків коментарів. Дужки рахуються.
Глибина: вкладені керувальні конструкції, зовнішня дужка методу не рахується.
Межа: лише src/Legacy/*.cs; тести, інші лабораторні та generated obj виключені.
Метрики методички ілюстративні: у нашому форматуванні Handle має інший LOC; CC 17 збігається.
Дублювання: два екземпляри одного алгоритму суми/знижки/доставки, після — один. Не видаємо кількість подібних фізичних рядків за точний результат детектора клонів.
Магічні числа: сім різних бізнес-значень (нуль та індекс циклу виключені).
