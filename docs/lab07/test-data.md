# План даних до тестів

Клас TransferDiscountPolicy для варіанта 6: знижка на вартість складського відвантаження. Це окрема навчальна політика, не заміна тарифів ЛР6. Базова вимога: постійний одержувач 5%, вартість від 1000 включно додає 10%, округлення decimal.Round до 0.01 (ToEven). Від'ємна сума — ArgumentOutOfRangeException. Вимогу стелі 150 додаємо окремим циклом TDD.

| Клас | amount | isRegular | Очікувано до TDD |
|---|---|---|---|
| некоректний | -0.01, -1000 | true | ArgumentOutOfRangeException, ParamName=amount |
| нижня межа | 0 | false | 0 |
| звичайний постійний | 400 | true | 20 |
| перед порогом | 999.99 | false | 0 |
| перед порогом постійний | 999.99 | true | 50 |
| точна межа | 1000 | false | 100 |
| точна межа постійний | 1000 | true | 150 |
| після межі | 1000.01 | false | 100 |
| округлення до парного | 0.1, 0.3 | true | 0, 0.02 |

Нова вимога TDD: DiscountFor(5000,true) має повертати 150 замість 750. Стеля відсутня у базовій реалізації; червоний коміт змінює тільки тести. Межі нової стелі: 999.99, 1000, 1000.01 і 1000.04 для isRegular=true; очікування після TDD 50,150,150,150.
