# Іменовані константи та видалений код

| Літерал | Константа | Пояснення |
|---|---|---|
| 0.2m | VatRate | Масштаб збережено: не 0.20m. |
| 1000 | RegularDiscountThreshold = 1000m | Перевірка суворо >. |
| 0.9m | RegularDiscountRate = 0.10m | Множення на 1m - частка знижки. |
| 5000 | LargeTransferThreshold = 5000m | Перевірка суворо >. |
| 0.85m | LargeTransferDiscountRate = 0.15m | Множення на 1m - частка знижки. |
| 10 | BulkLineCount | Перевірка суворо >, тобто від 11 рядків. |
| 100 у відніманні | BulkDiscountAmount = 100m | Віднімається перед ПДВ. |
| 100 у порівнянні | MaxLineCount | Перевірка суворо <, тобто до 99 рядків. |
| 2 у перевірці назви | MinRecipientNameLength = 3 | > 2 замінено еквівалентним >= 3. |
| 2 в Round | AmountDecimalPlaces | Округлення підсумку. |
| 0, 1, 2, 3 у станах | StatusNew, StatusApproved, StatusDispatched, StatusCancelled | Правила переходів не змінено. |

Індекси масиву, його розмір 3 і службові лічильники не перетворювалися на предметні константи.
Початковий стан int дорівнює 0 без явної ініціалізації; це збігається зі StatusNew.

Видалено присвоєння total = total та порожню гілку else. Видалено директиви using System, System.Collections.Generic і System.Linq, які дублювали ImplicitUsings або не використовувалися.
Закоментовані поле prim і стара знижка видалені під час очищення коментарів на попередньому етапі; вони доступні в історії Git.
