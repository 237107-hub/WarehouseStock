# Класова модель WarehouseStock

ЛР4, варіант 6, група 471, Здравков Максим Юрійович.
Модель зафіксована до реалізації нових класів.

| Сутність | Роль | Незмінність | Інваріант |
|---|---|---|---|
| TransferLine | Позиція переміщення | sealed record; get-only | Sku не порожній; Quantity > 0; UnitPrice >= 0 |
| Transfer | Документ між складами | Змінний агрегат, private set для стану | Id, SourceWarehouseId, DestinationWarehouseId > 0; склади різні; позиції додаються лише в New |
| Warehouse | Довідник учасників | sealed record; get-only | Id > 0; Name не порожнє; Email містить @ |
| Product | Довідник товарів | Змінний залишок через методи | Sku, Title не порожні; Price > 0; Stock >= 0 |
| ArchivedTransfer | Архівне подання | Композиція; get-only | Вкладений документ у Completed або Cancelled; ArchivedAt >= CreatedAt |

| Зі стану | До стану | Метод та умова |
|---|---|---|
| New | Approved | Approve; щонайменше одна позиція |
| New | Cancelled | Cancel; без додаткових умов |
| Approved | InTransit | Dispatch |
| Approved | Cancelled | Cancel |
| InTransit | Completed | Complete |
| Completed | — | Термінальний стан; будь-яка зміна заборонена |
| Cancelled | — | Термінальний стан; будь-яка зміна заборонена |

Зворотні переходи не передбачені. AddLine дозволено лише в New. Публічних
сетерів або init у нових сутностей немає. Зовнішня колекція — ReadOnlyCollection
над приватним List, тому приведення до ICollection не дозволить запис.
Позиції незмінні, отже через елемент колекції також не можна обійти інваріант.

## Припущення

Облікова ціна позиції — знімок ціни на дату документа, гроші decimal.
Пошта Warehouse перевіряється навчальним правилом @, без мережевої перевірки.
Дати — DateOnly, задаються явно. Документ не списує товар автоматично:
атомарні залишки двох складів і транзакції не входять до ЛР4.
Product.Receive/Dispatch контролюють окремий залишок; сервіс лише реєструє
документ, рахує вартість і викликає переданий сповіщувач.
RegularPricingPolicy повертає Amount; DiscountPricingPolicy приймає ставку
від 0 до 0.5; VipPricingPolicy дає 10%. Округлення кожної позиції — ToEven,
2 знаки. Це окремий контракт ЛР4; послідовні знижки ЛР3 залишено в Documents.
Архів дозволено створювати лише для термінального документа: зовнішнє
посилання більше не може змінити стан чи позиції вкладеного документа.

## Межі відповідальності

ITransferRepository: Add, GetById, GetAll. IPricingPolicy: PriceOf.
INotifier: Notify. TransferService приймає всі три абстракції в конструкторі.
TransferCsvReport формує рядок без запису на диск; сповіщувач пише тільки
до явно переданого TextWriter. Залежності складає Program.cs, контейнера немає.
Legacy-приклади будуть у тестовому проєкті для аудиту, без реальної SMTP-відправки.
Код ЛР3 та його 38 регресійних тестів збережено; для ЛР4 додаються рівно 3 Fact.
