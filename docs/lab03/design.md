# Рішення щодо декомпозиції

Варіант 6: складські залишки та переміщення. Навчальні знижки з методички
збережено як правила облікової вартості переміщення. Paid/ Shipped у прикладах
адаптовано до Approved/Dispatched. Це не повноцінна система складського обліку.

| Було | Групування |
|---|---|
| clientName, clientEmail, isRegular | RecipientInfo(Name, Email, IsRegular) |
| docId, lines, createdAt, couponCode, status, deliveryPrice | init-властивості TotalRequest разом із Recipient |
| newStatus out і decimal return | TotalResult(Total, NewStatus) |
| printToConsole | Вилучено; App сам викликає принтер |

TotalRequest — непозиційний record, щоб не створювати семипараметровий
конструктор усупереч межі 4. RecipientInfo має 3, TotalResult має 2 аргументи.
TransferLine — record з init-властивостями. Колекція IReadOnlyList не гарантує
глибокої незмінності: викликаючий код не повинен змінювати список паралельно.
Функції його не змінюють. Тип enum перевіряється Enum.IsDefined, бо приведення
числа може створити значення, не оголошене в переліку.

Порядок: позиції з гуртовою знижкою → постійний одержувач → обсяг → купон
→ неділя → доставка → нуль для Cancelled / округлення ToEven → наступний стан.
Порожній список, null, неправильні id/пошта/артикул/кількість/ціна/доставка/стан
дають виняток; повернення -1 з еталона навмисно замінене контрактом.
Пошту перевірено лише за правилом методички (наявність @), без SMTP-перевірки.
Невідомий або null-купон означає нульову знижку. Нульова ціна допустима.
Переповнення decimal штатно дає OverflowException; прихованого обрізання немає.

| Рутинa | CQS | Ефект |
|---|---|---|
| Calculate та 7 правил | запит | повертають значення, не змінюють аргументи |
| DocumentReport.TextOf | запит | створює локальний StringBuilder, повертає string |
| DocumentReportPrinter.Print | команда | void; запис лише до переданого TextWriter |
| Ensure... | передумова | перевіряє, при порушенні кидає виняток |

Раніше Process мав процедурну зв’язність, керувальне зчеплення з printToConsole,
зовнішнє зчеплення з Console та 11 аргументів. Calculate тепер функціонально
зв’язний, залежить від DTO і функцій правил за даними. TextOf працює з аргументами,
числа форматує через InvariantCulture і LF. Принтер зберігає зовнішній ефект,
але залежність TextWriter явна; її можна замінити StringWriter у тесті.
Скелет Domain залишено для сумісності навчального проєкту; Documents містить
окремий DTO розрахунку. Старі Legacy-модулі видалені з продуктивного коду.
Еталон знаходиться лише в тестах і в історії Git.
